## 1. 设计目标

将 4 维环境数据(温度/湿度/光照/土壤湿度)转换为单一的健康综合评分(0–100),并输出:
- 各维度状态(正常/偏高/偏低 等)
- 综合健康等级(优秀/良好/一般/较差/危险)
- 养护建议文案

**架构:规则引擎 + 加权评分**(plan_v2 §7.1),分三阶段:

```
阶段一 单维度评分  →  阶段二 综合加权  →  阶段三 养护建议
 (0-100/维度)        (0-100 综合)        (状态组合匹配模板)
```

## 3. 单维度评分规则(梯形隶属度)

采用 plan_v2 §7.2 的梯形隶属度模型。以温度为例(其余维度同理):

设适宜区间为 `[min, max]`,实测值为 `x`。

| 偏离情况 | 条件 | 评分 | 状态 |
|----------|------|------|------|
| 正常 | `min ≤ x ≤ max` | 100 | 正常 |
| 轻微异常 | 超出范围 < 10% | 80 | 偏高/偏低 |
| 中度异常 | 超出范围 10%–30% | 50 | 偏高/偏低 |
| 严重异常 | 超出范围 > 30% | 20 | 偏高/偏低 |

### 3.1 "超出范围百分比"计算

```
若 x > max: deviation = (x - max) / max
若 x < min: deviation = (min - x) / min   # min>0 时
            若 min == 0: deviation = (0 - x) / max  # 用 max 做基准,防除零
否则:        deviation = 0
```

### 3.2 各维度状态判定方向

| 维度 | 偏高方向状态 | 偏低方向状态 |
|------|--------------|--------------|
| 温度 | 偏高 | 偏低 |
| 湿度 | 偏高 | 偏低 |
| 光照 | 过强 | 不足 |
| 土壤湿度 | 过湿 | 过干 |

## 4. 综合评分权重(plan_v2 §7.3)

默认等权重 25%,后续可按植物品种调整(如多肉提高光照+土壤权重,降低湿度权重)。

| 维度 | 默认权重 | 说明 |
|------|----------|------|
| 温度 Temperature | 25% | 影响光合/蒸腾 |
| 空气湿度 Humidity | 25% | 影响气孔开合 |
| 光照强度 Light | 25% | 影响光合效率 |
| 土壤湿度 Soil Moisture | 25% | 根系吸水关键 |

```
health_score = round(
    0.25*temp_score + 0.25*humidity_score + 0.25*light_score + 0.25*soil_score
)
```

> 第二天将权重抽成配置(按 plant_id 查表),支持品种差异化。

## 6. 养护建议模板(plan_v2 §7.5 示例)

基于各维度状态组合匹配建议文案。第一天先列基础模板,第三天落地为规则引擎。

| 状态组合 | 建议文案 |
|----------|----------|
| 温度偏高 + 土壤偏干 | 当前温度偏高且土壤干燥,建议移至阴凉处并适量浇水,避免中午高温时段浇水。 |
| 光照不足 + 湿度偏高 | 当前光照不足,建议移至光线明亮处;空气湿度偏高,注意通风防霉。 |
| 全部正常 | 当前环境条件良好,继续保持现有养护节奏即可。建议每周检查一次土壤湿度。 |
| 多维度危险(≥2 维评分≤20) | ⚠️ 紧急提醒:多个环境指标严重偏离,请立即检查植物状态并调整养护措施! |
| (其他组合) | 第二天补充:按"最严重维度优先"生成针对性建议。 |
