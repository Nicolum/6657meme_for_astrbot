# Roguelike 地牢探险游戏 v2.0（增强版）

一款基于 Windows 控制台的 C++ Roguelike 地牢探险游戏。v2.0 新增职业、技能、远程武器、护盾、升级、关卡类型等系统。

## 项目结构

```
Roguelike/
├── main.cpp              # 程序入口，启动菜单
├── Game.h / Game.cpp     # 游戏主控类：渲染、输入、战斗、技能、存档
├── Entity.h / Entity.cpp # 实体类：Entity基类 + Player/Monster/Item派生类
├── Map.h / Map.cpp       # 地图类：房间与走廊的随机生成
├── Skill.h / Skill.cpp   # 技能系统：技能库 + 升级抽选
├── Career.h              # 职业定义（枚举与中文名）
├── CMakeLists.txt        # CMake 构建脚本
├── build_msvc.bat        # MSVC 一键编译脚本
└── README.md             # 本文件
```

## 编译方法

### 方法一：g++ 直接编译（推荐）

```bash
g++ -std=c++17 -O2 -Wall main.cpp Game.cpp Entity.cpp Map.cpp Skill.cpp -o Roguelike.exe
```

> g++ 默认按 UTF-8 解析源文件，含中文注释无需额外选项。

### 方法二：MSVC (cl.exe) 编译

源文件含中文注释，MSVC 必须加 `/utf-8`。双击 `build_msvc.bat` 即可：

```bat
build_msvc.bat
```

等效命令行：

```bat
call "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
cl /EHsc /std:c++17 /utf-8 /W3 /D_CRT_SECURE_NO_WARNINGS main.cpp Game.cpp Entity.cpp Map.cpp Skill.cpp /Fe:Roguelike.exe
```

### 方法三：CMake 构建

```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

## 运行

双击 `Roguelike.exe`，按 ENTER 开始，然后选择职业（1/2/3）。

## v2.0 新增系统

### 1. 职业系统（开局3选1）

| 职业 | HP/MP | 攻/防 | 初始武器 | 初始技能 | 定位 |
|------|-------|-------|----------|----------|------|
| 战士 | 40/10 | 6/3 | 铁剑(近战) | 重击(近战2倍) | 正面硬刚，高生存 |
| 法师 | 24/30 | 4/1 | 新手法杖(远程) | 火球术(直线1.8倍) | 远程爆发，脆皮高蓝 |
| 游侠 | 30/18 | 5/2 | 短弓(远程) | 精准射击(直线1.6倍) | 均衡远程，灵活机动 |

### 2. 技能系统（蓝条+冷却+升级抽选）

- 共 14 个技能，分战士系/法师系/游侠系/通用。
- 消耗 MP，有冷却回合数。
- **升级时 3 选 1**：从职业匹配的未学/可升级技能中随机抽 3 个，按 1/2/3 选择。
- 已学技能可继续升级（每级 +3 威力、-1 消耗），最高 3 级。

技能效果类型：远程直线伤害 / 近战伤害 / 范围AOE / 治疗 / 护盾 / 攻击增益。

### 3. 远程武器与瞄准

| 武器类型 | 攻击方式 |
|----------|----------|
| 近战(剑) | 移动撞向怪物即攻击 |
| 长矛(范围) | F+方向，攻击相邻格 |
| 弓(远程) | F+方向，直线6格首个敌人，1.0倍伤害 |
| 法杖(远程) | F+方向，直线6格首个敌人，0.8倍伤害 |

按 F 进入瞄准模式 → WASD 选方向 → 自动命中直线上第一个怪物。

### 4. 护盾机制

- 护盾是额外血量，**优先承受伤害**，被击穿后才扣 HP。
- 来源：护盾道具、技能（钢铁意志/护盾充能/闪避本能）、宝箱、奖励关。
- 升级时护盾清零。

### 5. 经验与升级

- 击杀怪物获得经验（`exp = hp/2 + 2`，Boss给40+）。
- 升级公式：`expToNext = 20 + playerLevel * 10`。
- 升级效果：maxHP+5、maxMP+3、**回满HP/MP**、弹出技能 3 选 1。

### 6. 关卡类型（随机出现）

| 类型 | 出现条件 | 内容 |
|------|----------|------|
| 普通关 | 70% | 5-8怪物 + 道具 + 钥匙（需钥匙下楼）|
| 奖励关 | 15% | 无怪物，4-6宝箱，**回满HP/MP+护盾+5**，直接下楼 |
| Boss副本 | 15%(level≥3) | 1只远古巨龙D，击败才能下楼，不恢复血量 |

**进入恢复**：普通关恢复30%HP+20%MP，奖励关回满，Boss关不恢复。

### 7. Boss机制

- 符号 D，HP=50+层数×10，攻击=8+层数×2。
- 相邻时有30%概率**蓄力**（下回合2倍重击，有提示）。

## 技术要点

- **渲染**：`SetConsoleCursorPosition` + `SetConsoleTextAttribute` 无闪烁彩色绘制，隐藏光标。
- **实体管理**：`std::vector<std::unique_ptr<Monster/Item>>` 自动释放内存。
- **面向对象**：`Entity` 基类，`Player`/`Monster`/`Item` 派生类，`Player` 重写 `takeDamage` 实现护盾逻辑。
- **技能系统**：`Skill` 结构体 + 静态技能库 + `rollSkillChoices` 升级抽选。
- **存档**：二进制格式 v2，含魔数与版本校验，序列化职业/MP/护盾/经验/技能/武器/关卡类型。

## 存档兼容

- v2 存档版本号 = 2，与 v1 不兼容（结构变化较大）。
- 读取时校验魔数 `RGLK` 与版本号，不匹配则拒绝。

## 已知限制

- 控制台不支持 emoji，用 ASCII 字符 H/M/W/K/T/P/C 替代图标。
- 存档文件 `save.dat` 生成在可执行文件同目录下。
- F5/F7 功能键通过扫描码检测，与字母键不冲突。
